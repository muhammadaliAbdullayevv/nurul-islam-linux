# Nurul Islam

**Nurul Islam** is a free, ad-free, offline-capable Islamic companion for **Android**, **Web**, and **Linux Desktop (Fedora / GTK3 + WebKit2GTK)** with full multilingual support (**O'zbek Lotin**, **Ўзбек Кирилл**, **Русский**, and **English**).

Website: [https://nurulislam.mabdullayev.dev](https://nurulislam.mabdullayev.dev)

## Features
- **Holy Qur'an (114 Surahs):** Arabic Uthmani Mushaf script, Uzbek/Russian/English translations, word-by-word synced audio recitations, bookmarks, and offline saving.
- **Accurate Prayer Times & Ramadan Calendar:** Hanafi & Standard calculation methods with Uzbekistan regional, district, and village precision.
- **Muallimi Soniy & Tajweed Trainer:** 10 progressive lessons (*Ahmad Hodiy Maqsudiy* method), interactive audio Qaida practice board, 5 Makhraj articulation zones, and color-coded Tajweed examples.
- **Hifz Memorization Trainer:** 18 short prayer Surahs & Duas with audio repeat loops and 3-stage word-hiding practice.
- **Everyday Hanafi Fiqh Q&A & Life Guides:** Searchable Hanafi rulings with classical references, 8 real-life guides, 40 Fards, Selected Ayahs, Hadiths, Morning/Evening Adhkar, and Duas.
- **Seerah & Stories of the 25 Prophets:** Chronological timeline of Prophet Muhammad ﷺ and stories of all 25 Qur'anic Prophets.
- **99 Names of Allah (Asma ul-Husna):** Audio, solo quiz, and live 1v1 quiz battle.
- **Islamic Knowledge Quiz:** 120 sourced questions across 6 topic decks with Smart Mistake Review.
- **Daily Worship Tools:** Digital Tasbih, Qibla compass, Qazo prayer tracker, Zakat calculator, Nearby Masjids map, and Verified Masjid Support (*Ehson & Hashar*).

## Install on Fedora Linux
```bash
sudo dnf install -y https://nurulislam.mabdullayev.dev/linux/nurul-islam-latest.rpm
```

## Build From Source
```bash
npm install
npm run build
```
